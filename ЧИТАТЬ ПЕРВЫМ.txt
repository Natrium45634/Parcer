ХРОНИСТ — генератор фэнтезийных историй
=======================================

САМЫЙ ПРОСТОЙ ПУТЬ: ГОТОВАЯ ПРОГРАММА ДЛЯ WINDOWS
--------------------------------------------------

Ничего ставить не нужно — ни Python, ни библиотек. Нужен один файл.
Прямая ссылка на скачивание:

  https://github.com/Natrium45634/Parcer/releases/latest/download/Chronist.exe

Или страница выпуска со всеми файлами:

  https://github.com/Natrium45634/Parcer/releases/latest

Запускается двойным щелчком. Файл можно переименовать хоть в
«Хронист.exe», положить куда угодно и сделать ярлык на рабочем столе
обычным способом (правый клик -> «Отправить» -> «Рабочий стол»).

При первом запуске Windows может спросить, доверяете ли вы программе:
она не подписана сертификатом, поэтому нажмите «Подробнее» ->
«Выполнить в любом случае».


ЗАПУСК ИЗ ИСХОДНИКОВ (если хочется свежую версию)
--------------------------------------------------

Windows   двойной щелчок по файлу   Запустить.bat
macOS     двойной щелчок по файлу   Запустить.command
Linux     ./Запустить.sh

Для этого пути нужен установленный Python 3.8 или новее. В Windows он
ставится одним файлом с python.org; при установке обязательно поставьте
галочку «Add Python to PATH».


КАК ПОЛЬЗОВАТЬСЯ: ТРИ ШАГА
---------------------------

Программа открывается мастером создания мира.

  ШАГ 1. МИР
    Сид (любое слово или код вида KR7M-93XD) и сколько лет истории
    прожить. Этого уже достаточно — можно идти на третий шаг.

    Ниже — тонкая настройка: 69 шкал от 0 до 100, от скорости
    размножения народов до частоты бедствий, смут и заговоров.
    Пятьдесят — «как задумано». Слева у каждой шкалы замок: если его
    поставить, кнопка «Бросить кости» эту шкалу не тронет.

  ШАГ 2. КАРТА
    Три способа:
      * Гексовая карта Worldforge — программа делает её сама тем самым
        картогенератором: тектоника, эрозия, климат, реки, 40 биомов,
        недра, живность, логова и племена. Размер (малая 160×96,
        средняя 280×168, большая 500×300), сколько материков, замкнут
        ли мир по долготе и 18 ползунков со своими замками. Кнопка
        «Ещё раз, по-другому» бросает новую карту, пока не понравится.
        Готовую карту видно тут же и можно сохранить в файл .world.
        Малая карта считается около десяти секунд, средняя — полминуты,
        большая — минуты полторы: это не спешка, а честная физика.
      * Своя карта .world — любая, лишь бы формат тот же.
      * Без карты — земли придумает сам движок.

  ШАГ 3. СОЗДАНИЕ
    Короткая сводка того, что выбрано, и кнопка «Создать мир».
    Десять тысяч лет истории считаются одну-две минуты.
    Внизу сводки — КОД МИРА: одна строка, в которой лежит всё. Сид,
    длительность, густота, карта и все шкалы. Вставьте чужой код в поле
    «Код мира» на первом шаге — и получится тот самый мир на той самой
    карте. Сид карты по умолчанию следует за сидом мира, так что одно
    слово даёт один мир целиком.

После этого окно переключается на летопись: 52 вкладки с событиями,
державами, войнами, верами, бедствиями, нашествиями и их следами,
судьбами людей, былями, жизнью городов, праздниками, делами богов,
весом имён.

Три из них стоит открыть первыми:

  История мира ..... вся летопись с отбором: за какие годы, насколько
                     важное, о чём, на какой земле, у какой державы и по
                     какому слову. Оттуда же — «отчего это вышло» и
                     переход на карту к месту события.
  Карта мира ....... гексовая карта со всеми слоями: биомы, рельеф,
                     державы по годам, реки, города, границы. Колесо
                     приближает, щелчок по гексу рассказывает о месте
                     всё — вплоть до того, кто владел этой землёй в
                     выбранный год и какая беда по ней прошла.
  Временная шкала .. весь мир на один названный год.

Во вкладке «Праздники» видно то, чего по событиям не увидеть: как
память стареет. Праздник не рождается праздником — сперва к месту просто
приходят и вспоминают, и девять таких дней из десяти тают вместе с теми,
кто помнил. А у дошедшего до календаря начинается своя жизнь: его
забирает себе держава, запрещает новая власть, возвращает следующая — и
повод теряется раньше обряда. Костёр жгут и через тысячу лет; зачем —
уже не говорят, а говорят неправду. У каждого дня там видно оба смысла
сразу: с чего он начался и чем считается теперь.

А во вкладке «Личности» стоит отбор: раса, вес в истории, титул, роль,
пол, годы и слово в имени. Людей в мире на десять тысяч лет — сто с
лишним тысяч, и список такой длины можно только прокручивать мимо;
«мировые и выше» оставляют четыре десятка имён на весь мир.

Кнопка «Новый мир» вверху возвращает к мастеру.


ЧТО СОХРАНЯЕТСЯ (меню «Файл»)

  Сохранить политическую карту ... chronicle.json для картогенератора
  Карта .world ................... кнопка на шаге «Карта»


БЕЗ ОКНА, ИЗ КОНСОЛИ (по желанию)
----------------------------------

    python main.py --cli --seed "Ясень-7" --years 10000 --out летопись.txt
    python main.py --cli --map-random средняя --save-map карта.world
    python main.py --cli --tune war_rate=15,calamity_rate=85
    python main.py --tune-list        список всех шкал настроек
    python main.py --help
