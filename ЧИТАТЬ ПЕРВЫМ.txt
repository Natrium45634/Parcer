ХРОНИСТ — генератор фэнтезийных историй
=======================================

КАК ЗАПУСТИТЬ (программировать ничего не нужно)
-----------------------------------------------

Windows   двойной щелчок по файлу   Запустить.bat
          значок на рабочем столе:  Создать ярлык на рабочем столе.bat

macOS     двойной щелчок по файлу   Запустить.command
          (в первый раз: правый клик по файлу -> «Открыть»)

Linux     ./Запустить.sh
          значок в меню программ:   Создать ярлык (Linux).sh
          если окно не открылось:   sudo apt install python3-tk

Единственное требование — установленный Python 3.8 или новее.
В Windows и macOS он ставится одним файлом с python.org, всё
остальное уже лежит в этой папке. При установке в Windows
обязательно поставьте галочку «Add Python to PATH».


ЧТО ДЕЛАТЬ В ОКНЕ
-----------------

1. Слева поле «Сид» — любое слово или код вида KR7M-93XD.
   Кнопка «Случайный» рядом бросает новый код.
2. «Длительность, лет» — сколько лет прожить миру (по умолчанию
   10000). Ниже — «Земель на карте» и «Плотность событий».
3. Кнопка «Сгенерировать мир». Один и тот же сид всегда даёт
   один и тот же мир, до последнего имени и до последней даты.
4. Готовый мир раскладывается по вкладкам: летопись, державы,
   расы, войны, вера, бедствия, торговля, карта и прочее.
5. Меню «Файл» — «Сохранить летопись в текст…» (.txt),
   «Сохранить мир…» (.json), «Открыть мир…» и «Сохранить
   политическую карту (chronicle.json)…».


ГЕОГРАФИЧЕСКАЯ ГЕКСАГОНАЛЬНАЯ КАРТА
------------------------------------

В папке maps лежит готовая карта aurora-7.world из
TECTONIC WORLDFORGE. В окне программы нажмите «Карта мира:
Выбрать .world…» и укажите её — вся история будет опираться
на настоящую географию: горы, реки, плодородие, руды, климат.
Можно подложить любую свою карту .world; кнопка «Убрать»
возвращает выдуманную географию.

Политическая карта строится сама: каждая раса занимает
в первую очередь желанные ей гексы (дворфы — хребты,
эльфы — леса, люди — плодородные равнины), недружелюбные
земли остаются серой зоной и входят в державы позже.


БЕЗ ОКНА, ИЗ КОНСОЛИ (по желанию)
----------------------------------

    python main.py --cli --seed "Ясень-7" --years 10000 --out летопись.txt
    python main.py --cli --seed "Ясень-7" --map maps/aurora-7.world --out мир.json
    python main.py --help
