КАРТЫ МИРА
==========

Сюда кладутся файлы .world — карты из TECTONIC WORLDFORGE.

Если выбрать такую карту перед генерацией, история перестанет опираться
на выдуманную движком сетку земель и будет строиться по настоящей
географии: хребтам, рекам, климату, рудам и полям магии.

Что карта даёт истории:

  * земли, их местность и ёмкость — из биомов и плодородия;
  * места под города — из пригодности гекса для жизни, рек и берегов;
  * лагеря злых народов — из дикости округи;
  * природные бедствия — из маски местных угроз: где вулкан, там
    извержения, где сушь — засухи, где берег — цунами;
  * долгие перемены климата — из ленты климата, вшитой в сид карты:
    ледниковый период случится ровно в тот год, который она назначила;
  * спящие логова существ — из логовов карты: через века их разбудят,
    и старая беда выйдет наружу;
  * мировоззрение богов — из поля магии: в землях с дурной славой
    охотнее приживаются тёмные культы.

Раса, которой на карте негде жить, в мир не приходит вовсе. Мир без гор
остаётся без дворфов, мир без болот — без ящеролюдов.

КАК СДЕЛАТЬ СВОЮ КАРТУ

  1. Откройте TECTONIC WORLDFORGE.
  2. Сгенерируйте мир с любыми настройками.
  3. Нажмите «⤓ .world» и положите файл в эту папку.
  4. В генераторе истории выберите его кнопкой «Выбрать .world…».

ОБРАТНО НА КАРТУ

После генерации сохраните «Файл → Сохранить политическую карту
(chronicle.json)». Этот файл загружается во вкладке «Страны»
картогенератора — и десять тысяч лет истории проигрываются по годам
прямо на вашей карте: державы возникают, растут, делятся и гаснут.

aurora-7.world — карта для примера, 160×96 гексов.
